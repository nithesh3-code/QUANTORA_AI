# 🌌 QUANTORA AI
**A High-Performance Quantum & Classical Research Platform**

QUANTORA AI is a locally hosted, full-stack scientific application designed to execute, store, and analyze classical optimization algorithms and quantum circuit simulations. It features a custom validation engine that cross-verifies LLM mathematical analysis against raw database integers to prevent AI hallucinations.

## 🚀 Core Features
* **Classical Lab:** Runs Google OR-Tools for complex Knapsack optimization.
* **Quantum Lab:** Simulates Bell State entanglement and Grover's Search algorithms using Qiskit Aer.
* **Research Dashboard:** Persistent SQLite database tracking with CSV data export.
* **AI Assistant:** Integrated Groq API (GPT-OSS 120B) for high-level scientific reasoning.
* **Validation Engine:** Custom Regex-based security shield ensuring mathematical integrity.
* **Cyberpunk UI:** Custom CSS styling for an immersive, dark-mode terminal aesthetic.
